# 企画書

## プロジェクト基本情報

| 項目 | 内容 |
|------|------|
| プロジェクト名 | TasteGuide（テイストガイド） |
| 副題 | 多言語対応レストラン口コミプラットフォーム |
| 対象地域 | ウズベキスタン・タシケントを想定 |
| 開発形態 | 大学 Cowork プロジェクト |
| リポジトリ名 | `cowork-restaurant-reviews` |

---

## 1. 背景（Background）

タシケントではレストラン数が増加しており、観光客・在住外国人・地元住民が「どこで食べるか」を判断する際、口コミや多言語情報の不足が課題となっている。既存の地図アプリや SNS では、料理ジャンル・価格帯・来店体験を一元的に比較しにくい。

また、ウズベク語・ロシア語・英語・日本語など、利用者の母語が多様であるため、単一言語のみのサービスでは情報アクセスに格差が生じる。

---

## 2. 課題（Problem）

本プロジェクトが解決しようとする具体的な課題は以下のとおりである。

1. **情報の分散** — レストラン情報が各媒体に散在し、評価・写真・住所を比較しにくい。
2. **言語の壁** — 外国人や日本語話者が、現地語のみのメニューや説明に頼らざるを得ない。
3. **信頼できる口コミの不足** — 来店日・評価・本文が揃った、再現性のあるレビューが少ない。
4. **運営側の負担** — 店舗情報の登録・公開・モデレーションを行う管理手段が必要。

---

## 3. 目的（Purpose）

TasteGuide は、上記課題に対し、**多言語 UI** と **ユーザー投稿型レビュー** を備えた Web アプリケーションを提供することを目的とする。

具体的には次を達成する。

- タシケントのレストランをカテゴリ・検索・フィルタで発見できるようにする。
- 認証済みユーザーが評価・本文・画像付きレビューを投稿できるようにする。
- 管理者が店舗・カテゴリ・ユーザー・レビューを管理できるようにする。
- 将来の本番運用（Vercel + ホスト型 PostgreSQL）を見据えた構成とする。

---

## 4. 対象ユーザー（Target users）

| ユーザー種別 | ニーズ |
|--------------|--------|
| **一般ユーザー（USER）** | レストラン検索、詳細閲覧、口コミ投稿・編集・削除、プロフィール管理 |
| **管理者（ADMIN）** | 店舗 CRUD、カテゴリ管理、レビュー・ユーザー管理、公開状態の制御 |
| **未ログインゲスト** | 一覧・詳細の閲覧、ログイン／登録、言語切替 |

想定ペルソナ例：

- タシケント在住の大学生（ウズベク語／ロシア語）
- 出張・留学中の日本人（日本語 UI）
- 英語圏の観光客

---

## 5. 主要機能（Main features）

実装済み機能のみを記載する（未実装の地図埋め込み等は含めない）。

### 5.1 公開機能

- ホーム画面（カテゴリ、高評価・新着レストラン）
- レストラン一覧（グリッド／リスト表示、検索、カテゴリ・都市・評価・価格帯・ソート）
- レストラン詳細（ギャラリー、説明、平均評価、レビュー一覧、住所表示）
- 404 ページ、エラー表示
- 4 言語対応（英語・ウズベク語・ロシア語・日本語）と URL ロケールプレフィックス（`/en`, `/uz`, `/ru`, `/ja`）

### 5.2 認証・アカウント

- メール／パスワードによる登録・ログイン（Auth.js + bcrypt）
- プロフィール閲覧、モーダルによるプロフィール編集（氏名・言語・ avatar）
- ログアウト
- ミドルウェアによる `/profile` 保護

### 5.3 レビュー

- ログインユーザーによるレビュー作成（評価 1〜5、タイトル、本文、来店日、画像）
- 本人レビューの編集・削除（ダイアログ UI）
- 他ユーザーレビューへの不正操作防止（サーバー側権限チェック）

### 5.4 管理機能

- 管理ダッシュボード（統計概要）
- レストラン CRUD（多言語説明、座標、公開フラグ、画像）
- カテゴリ CRUD（4 言語名称）
- レビュー一覧・管理
- ユーザー一覧・ロール管理
- `/admin` への ADMIN ロール限定アクセス

### 5.5 画像・データ

- 開発環境：`public/uploads/` へのローカル保存
- 本番環境：Cloudinary 連携（設定時）
- シードデータ：12 店舗、8 カテゴリ、20 レビュー等（`npm run db:seed`）

### 5.6 品質・デプロイ

- Vitest 単体テスト、Playwright E2E テスト定義
- TypeScript / ESLint / 本番ビルド検証
- Vercel + Neon／Supabase 向けデプロイ手順（`docs/DEPLOYMENT.md`）
