### 4.2 Fail したケース（要修正）

| ID | 内容 | 主な原因（調査結果） |
|----|------|----------------------|
| T001 | 新規登録 | 登録後リダイレクト待ちタイムアウト |
| T002 | ログイン UI | フォーム送信タイミング |
| T003 | ログアウト UI | セッション UI 操作 |
| T005（ADMIN 肯定） | 管理ダッシュボード | グローバル「Restaurants」リンクの strict モード衝突 |
| T006 | 言語切替 | URL ロケール変更の待機不足 |
| T007 | 検索 | クライアントルーター後 URL 未更新 |
| T008 | フィルタ | 同上 |
| T010—T013 | レビュー CRUD | 認証ヘルパー・セレクタ |
| T014—T016 | 管理 CRUD | フォーム・ダイアログ操作 |

### 4.3 E2E 改善施策（実施済み・計画中）

- Playwright 認証：`loginViaApi` による API ログイン補助
- フォーム `preventDefault` によるネイティブ GET 送信防止
- 今後：検索 E2E の `networkidle` / Enter キー、スコープ付きセレクタ
