## 2. 最終成果（Final result）

Cowork プロジェクトとして、**ブラウザから利用可能なフルスタック Web アプリケーション**を成果物とした。

- ローカル環境で `npm run dev` により即時デモ可能
- `npm run build` による本番ビルド成功
- Vercel + PostgreSQL（Neon/Supabase）+ Cloudinary へのデプロイ手順整備
- 日本語を含む **4 言語 UI** による国際的な利用シナリオの提示
- 大学提出用ドキュメント一式（企画・設計・テスト・報告）

## 6. 残存する制限（Remaining limitations）

1. **地図未実装** — 緯度経度は DB に保持するが、Leaflet UI は未組み込み。ユーザーは住所文字列のみ参照可能。
2. **E2E 自動化** — 19 ケース中 14 ケースが Fail。CI ゲートとしては未成熟。
3. **本番デモアカウント** — シードのデフォルトパスワードは公開デモ用。本番公開時は変更必須。
4. **画像** — 本番では Cloudinary 設定が必須。未設定時アップロード不可。
5. **README 一部古い記述** — Phase 表記が残る箇所あり。実装は CRUD・管理まで完了。
6. **Middleware 警告** — Next.js 16 における middleware → proxy 移行警告（ビルドは成功）。

## 10. 結語

TasteGuide は、タシケントのレストラン情報を **4 言語** で提供し、**ユーザー参加型の口コミ** と **管理者によるコンテンツ管理** を両立する Web プラットフォームとして完成した。技術的にはモダンな React エコシステムと型安全なサーバー設計を学び、テストとドキュメントを通じてソフトウェア工学の実践を行った。

今後は E2E 安定化と地図機能の追加により、実サービスに近い体験へ発展させることができる。
