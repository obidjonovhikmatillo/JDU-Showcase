## 1. テスト目的

本システム Taomchi が要件どおりに動作することを、自動テストおよび手動確認によって検証する。

特に以下の領域を対象とする。

- 認証・セッション管理（登録・ログイン・ログアウト・保護ルート）
- 権限制御（ADMIN のみのアクセス制限、レビューの本人制限）
- レストラン検索・フィルタ・詳細表示
- レビュー CRUD（作成・編集・削除）
- 管理画面 CRUD（店舗・カテゴリ・レビュー・ユーザー）
- 多言語 UI（言語切替・URL 変更）
- 画像バリデーション（形式・サイズ・空ファイル）
- 地図フォールバック（住所テキスト表示）

## 9. E2E テスト環境の制限

E2E テスト（Playwright）において 16 ケースが未 Pass となっている。これらは **アプリケーションの機能バグではなく、テスト自動化環境の制限** に起因する。主な原因は以下のとおりである。

| 原因 | 影響するテスト |
|------|-------------|
| 認証ヘルパーの `waitForResponse` タイムアウト | T002・T003 等、ログインを伴う全テスト |
| フォーム送信後の URL クエリ非同期更新 | T007（検索）・T008（フィルタ） |
| 複数要素へのストリクトモード違反（Playwright 厳格モード） | T005・T009・T013 |
| コンボボックス操作のタイムアウト | T014・T015・T016 |

これらのフローは手動ブラウザ確認で正常動作を確認済みであり、本報告書および作業報告書に明記している。
