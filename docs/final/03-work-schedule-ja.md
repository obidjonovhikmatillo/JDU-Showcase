## 4. リスクと対応（実績）

| リスク | 実際の対応 |
|--------|----------|
| 画像サービスの地域制限 | Cloudinary から Vercel Blob に切り替え（サービス無停止で移行） |
| E2E テスト不安定 | API ログイン補助の実装、Vitest 単体テストでコアロジックを担保 |
| 地図機能の未完成 | 住所テキスト表示で代替（T019 テストで意図的フォールバックを確認） |
| Windows / OneDrive での動作 | webpack モード（`npm run dev`）、組み込み PostgreSQL を使用して対応 |
| Next.js / Auth.js ミドルウェアの複合設定 | `auth.config.ts`（エッジ用）と `auth.ts`（サーバー用）を分離して解決 |
