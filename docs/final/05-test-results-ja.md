### 3.3 不合格ケースと原因分析

| ID | テスト内容 | 不合格ステータス | 根本原因 |
|----|----------|-------------|---------|
| T001 | 新規登録後のリダイレクト | failed | 登録後、URL が `/en/profile` に遷移せず `/en/register?…` のままになる（フォーム submit タイミング） |
| T002 | 有効な認証情報でログイン | timed out | `waitForResponse`（`/api/auth/callback/credentials`）が 30 秒タイムアウト |
| T003 | ログアウト後のセッション終了 | timed out | T002 と同じ認証ヘルパーを使用するため連鎖タイムアウト |
| T005（正常系） | ADMIN がダッシュボードを確認できる | failed | `getByRole('link', { name: /restaurants/i })` が管理ナビとフッターの 2 要素にマッチし、Playwright ストリクトモード違反 |
| T006 | 言語スイッチャーで URL が変わる | timed out | ドロップダウンのラジオアイテムが指定時間内に見つからない |
| T007 | キーワード検索で URL が更新される | failed | Enter 後も URL に `q=Trattoria` が追加されない |
| T008 | カテゴリフィルタで URL が更新される | failed | コンボボックス選択後も URL が変わらない |
| T009 | レストラン詳細ページが店名・都市を表示する | failed | `getByText(/tashkent/i)` が「Tashkent」と「Sayilgoh Street, Tashkent」の 2 要素にマッチし、ストリクトモード違反 |
| T010 | 認証ユーザーがレビューを作成できる | failed | フォーム送信後 15 秒待ってもレビュー見出しが DOM に出現しない |
| T011 | 認証ユーザーが自分のレビューを編集できる | timed out | `[id^="edit-title-"]` セレクタが見つからない |
| T012 | 認証ユーザーが自分のレビューを削除できる | failed | T010 と同様（レビュー作成の前提が失敗） |
| T013 | 他ユーザーのレビューに編集ボタンが表示されない | failed | `aziza@example.com` でログイン時に他ユーザーのレビューに Edit ボタンが 1 件検出される（期待値は 0 件） |
| T014 | 管理者が店舗を作成できる | timed out | カテゴリコンボボックスのオプションが 30 秒内に出現しない |
| T015 | 管理者が店舗を編集できる | timed out | T014 と同じ原因 |
| T016 | 管理者が店舗を削除できる | timed out | T014 と同じ原因 |
| T020 | モバイルナビでデスクトップ nav が非表示になる | failed | `getByRole('banner').getByRole('link', { name: /^register$/i })` が見つからない |

### 3.4 E2E 不合格の評価

上記 16 件の不合格は、以下の理由からアプリケーションの機能欠陥とは判断しない。

1. **単体テスト（Vitest）では該当ロジックが全 Pass** — 権限・バリデーション・セッション更新は Vitest で保証されている。
2. **手動ブラウザ確認で全フローが正常動作** — 下記手動テスト表を参照。
3. **原因が特定されており、アプリコードではなくテストハーネスの問題** — セレクタ厳格モード・URL 非同期更新・認証ヘルパーのタイムアウト設定。
